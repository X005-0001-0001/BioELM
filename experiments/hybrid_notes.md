# 循环+堆叠混合探索记录（expr-hybrid 分支）

日期：2026-10（GPU 开放后第一轮）
口径：deep_bench 协议（CPU 干净 500 条子集，固定 η=2e-3，h=192，3000 步）。
注意：本页为**干净 500 条子集**口径；与 deep 1.0.x 发布页（BOM 子集 499 条）绝对数有 +0.17 位移，
仅在页内互相对照。

## 结果

| 结构 | 参数 | valCE |
|---|---|---|
| 单层 | 304k | 4.7989 |
| 纯循环 K=2 | 304k | 4.6281 |
| **纯循环 K=4** | 304k | **4.4678** |
| 纯堆叠 L2 | 477k | 4.9474 |
| 混合 L2×K2 | 477k | 4.8163 |
| 混合 L2×K1（=纯堆叠） | 477k | 4.9474 |
| 混合 L3×K2 | 649k | 4.8786 |

## 结论（负结果）

1. 层内循环能改善堆叠（L2：4.9474 → 4.8163），但**混合仍远劣于纯循环**：
   参数多 57% 的 L2×K2（477k）打不过参数少 36% 的纯循环 K4（304k，4.4678）；
   甚至打不过只有一半有效深度的纯循环 K2（4.6281）。
2. 层堆叠的问题不在"每层太浅"，而在**层间接口**（下一层的输入是上一层的读出表示，
   局部规则下接口不可训练/不对齐）；层内加深缓解但不解决。
3. 再次确认 deep 分支结论：**深度应来自时间上的循环，而不是参数的堆叠**。

## 保留理由

接口对齐是唯一未探索的解法（如可学层间变换矩阵 + 局部对齐目标），
若未来要做真正的"分层电路"（并行分支/专家），本分支的对照与台架可直接复用。

复现：`python experiments/bench_hybrid.py`（BIO_DEEP_SUBSET=500）。
