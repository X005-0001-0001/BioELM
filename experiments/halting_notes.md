# 学习型停机探索记录（expr-halting 分支）

日期：2026-10（elastic 1.0.0 后）
口径：同 bench_elastic（CPU 干净 500 条子集，固定 η=2e-3，h=192，consist KMAX=4，3000 步）。

## 机制

- 小读出头：`p_halt = σ(sem_k·w + b)`（新增参数 m+1 = 49）
- 训练目标自监督、零人工阈值：`y_k = 1[CE_k ≤ CE_{k+1}]`（下一步无改善即该停），末步 y=1
- 学习规则：批量逻辑回归本地更新（与主电路同为局部规则；无 autograd）
- 推理：逐子步运行，`p_halt > 0.5` 即停（上限 KMAX）

## 结果

| 方式 | valCE | 平均深度 |
|---|---|---|
| 固定 K=1 | 4.5506 | 1 |
| 固定 K=2 | 4.3987 | 2 |
| **学习型停机** | **4.3987** | **2.000** |
| 固定 K=3 | 4.3778 | 3 |
| 固定 K=4 | 4.3870 | 4 |

## 结论（中性偏负）

1. 停机头**学对了**"最优全局预算"——稳定停在 K=2，质量精确等于固定 K=2（4.3987）。
2. 但按 batch 列粒度（8 token/列）取均值停机，无法把"逐 token 再分配"的潜力发挥出来；
   若硬 token 拿 3-4 步、易 token 拿 1 步，理论上同均深可优于均匀——本实现没有观测到。
3. 边际 CE 目标噪声大（单 token 前后步 CE 比较），停机头容易学到"全局平均"而非"逐 token 判据"。
4. 与 expr-autoloop 的语义收敛判据结论一致：**"何时停"本身不携带可白拿的收益**。

## 保留理由

- 停机头是独立的 49 参数模块，可与任何 elastic 模型叠加；训练成本可忽略；
- 若要继续：改为逐 token 阈值（非 batch 均值）+ 平滑的边际收益目标（如 3 步滑动），
  或用 RL 式局部资格迹直接优化"深度-准确率"权衡；需更大的 batch 与更长训练才能从噪声中分离。
